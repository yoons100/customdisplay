**Custom Display**

1. Custom Display는 Windows 시스템 트레이에서 외장 디스플레이의 해상도, 주사율, 색 공간을 조정하는 앱입니다. 
2. 사용자 지정 해상도로 변경하고 잘못 인식된 디스플레이 정보(EDID)를 수정할 수 있습니다.
3. 스위처/빔프로젝터에서 주로 사용하는 1080p, 1200p, 2160p, 2400p를 설정하기 편하게 만들었습니다.
4. 여러 화면의 배치와 출력 설정은 프리셋으로 저장하고 단축키로 불러올 수 있습니다.
5. 프리셋 및 설정파일은 문서 > CutomDisplay 폴더에 저장됩니다.
